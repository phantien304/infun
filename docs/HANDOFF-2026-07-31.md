## 2. Những chỗ dễ làm sai — đọc trước khi sửa tiếp

**`FragmentCache::facets()` cache HTML sidebar.** Sửa
`_side_bar_facets_static.blade.php` xong mà không xoá cache thì vẫn thấy giao
diện cũ, và sẽ mất thời gian đi tìm nguyên nhân ở chỗ khác:

```bash
php artisan tinker --execute="App\View\FragmentCache::forgetFacets();"
```

**nginx: location `^/(vcms|rcms)` KHÔNG được dùng `try_files … /index.php`.**
try_files sinh internal redirect tới `/index.php`, mà `/index.php` lại khớp
`location ~ \.php$` bên dưới → request quay về `fpm_pool` của storefront, phá
sạch bulkhead **mà vẫn trả 200**. Nên location đó gọi thẳng `fastcgi_pass` và
tự set `SCRIPT_FILENAME`.

**Read replica cho admin phải set CẢ HAI biến.** `config/database.php`
fallback cả read lẫn write về `DB_HOST`; chỉ đổi read mà quên write thì lệnh
ghi của CMS bay vào replica (`read_only`) → lỗi ngay lúc lưu sản phẩm. Compose
đã set sẵn `DB_READ_HOST1` + `DB_WRITE_HOST`.

**deptrac không dừng ở layer khớp đầu tiên.** `app/Services/Cms` bị loại khỏi
collector của Domain bằng `type: bool`; bỏ đoạn đó thì một class khớp cả hai
layer và Web import service CMS vẫn pass.

**`app/View` cố ý không thuộc layer nào.** `FragmentCache` bị chính Repository
gọi để invalidate; xếp nó vào Web thì sinh 3 vi phạm Domain→Web ngay ngày đầu.

**Đánh giá dùng radio, có mục "Tất cả đánh giá" (value rỗng).** Radio thuần
HTML không tự bỏ chọn được — bỏ mục đó thì người dùng lọc rồi là kẹt.

**Theme + Octane: đừng đăng ký namespace `web` trong service provider.** Octane
boot một lần rồi phục vụ nhiều host → khoá cứng theme của request đầu tiên.
Phải qua middleware `ResolveTheme`, và mỗi lần đổi namespace phải
`View::getFinder()->flush()`. Không lộ trên php-fpm nên rất dễ lọt qua dev.

**Khoá cache trang đã thêm `theme`.** Thiếu mảnh đó thì HTML của aurora.demo
được phục vụ cho nova.demo — trùng path, locale, currency nên trùng khoá.

**Entry CSS của theme phải `@import` base app.css, không copy.** Tailwind v4 dò
class theo `@source`; view không ghi đè rơi về base và cần utility bridge
Bootstrap ở đó.

**RAM.** t3.small 2GB đang chạy `PROD_PHP_REPLICAS=2`. Pool admin 6 worker ×
~90MB ≈ 540MB lấy khỏi storefront. Cân nhắc t3.medium, hoặc hạ `pm.max_children`
xuống 3, hoặc `PROD_ADMIN_PHP_REPLICAS=0` tới khi resize.

## 4. Việc tiếp theo, theo thứ tự

1. **Chạy các lệnh ở §5**, sửa nếu có lỗi, rồi commit. Cân nhắc **tách 3 commit**
   theo nhóm A / B / C ở §1 — chúng không liên quan nhau, và prototype (B) có
   thể muốn nằm branch riêng.
2. **Nối Blade theo prototype**: trang danh mục và trang sản phẩm. Bộ lọc đã
   xong; còn lưới sản phẩm, thanh sắp xếp, chip đang lọc, phân trang.
3. **Chip "đang lọc"** cho trang danh mục thật — hiện chỉ có trong prototype.
   Đây là thứ cho người dùng biết vì sao kết quả bị thu hẹp.
4. **Đếm facet** (số bên cạnh mỗi lựa chọn). Meilisearch trả sẵn
   `facetDistribution`; điểm mấu chốt là đếm phải **bỏ qua chính facet đang
   đếm**, nếu không chọn xong một mục thì mọi mục khác cùng nhóm về 0 và người
   dùng hết đường đổi ý.
5. **Giỏ hàng + checkout** — nơi backend mạnh nhất mà frontend chưa chạm: hold
   tồn kho, `FlashGateService`, coupon conditional update chống over-redeem.
6. Áp cấu hình bulkhead cho `docker-compose.staging.yml` (mới chỉ đụng production).
7. Dựng RDS Read Replica → điền `DB_ADMIN_READ_HOST`. **Đây mới là phần giảm
   tải lớn nhất** — tách container chỉ cách ly worker PHP, RDS master vẫn chung.
8. Đặt `/vcms`, `/rcms` sau VPN hoặc IP allowlist.

## 5. Lệnh phải chạy trước khi mở PR

```bash
# 1. Ranh giới module
composer install
composer boundary                 # deptrac phải PASS (kỳ vọng 0 vi phạm)

# 2. Hạ tầng
docker compose -f docker-compose.production.yml config >/dev/null
docker run --rm -v "$PWD/docker/nginx/default.lb.conf:/etc/nginx/conf.d/default.conf:ro" \
  nginx:1.27-alpine nginx -t

# 3. Ứng dụng
php artisan test
php artisan tinker --execute="App\View\FragmentCache::forgetFacets();"

# 3b. Hệ theme
npm run build                       # phải thấy entry themes/aurora/css/app.css
php artisan view:clear
THEME=aurora php artisan tinker --execute="dd(view()->getFinder()->getHints()['web']);"
#   → kỳ vọng 2 đường dẫn, themes/aurora/views đứng TRƯỚC web/views
# Thử tay: THEME=aurora + mở trang chủ → bento; bỏ THEME → giao diện cũ.
# Thử 2 host cùng lúc (quan trọng nhất, chỉ vỡ dưới Octane):
#   aurora.demo → bento, nova.demo → theme kia, KHÔNG lẫn nhau.

# 4. Chỉ khi index Meilisearch dựng TRƯỚC lúc rating_avg được khai báo
php artisan scout:sync-index-settings

# 5. Thử tay: /san-pham?filter[rating_min]=4  → chỉ còn sản phẩm >= 4 sao,
#    reload lại thấy radio 4 sao vẫn được tick (không nhảy về "Tất cả").
```
